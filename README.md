GSWA June Theme
A custom WordPress theme developed for the Gopalganj Social Welfare Association (GSWA).
Overview
GSWA June is a lightweight, responsive WordPress theme built specifically for a non-profit organization. The theme focuses on performance, maintainability, accessibility, and clean code while leveraging modern WordPress development practices.
Features
•	Responsive design for desktop, tablet, and mobile devices
•	Custom homepage sections
•	Advanced Custom Fields (ACF) integration
•	Custom Post Types support
•	Modular template parts
•	BEM-based CSS naming convention
•	Organized and modular CSS architecture
•	Optimized image handling
•	Mobile-friendly navigation
•	Clean and maintainable code structure
Technology Stack
•	WordPress
•	PHP
•	HTML5
•	CSS3
•	JavaScript
•	Advanced Custom Fields (ACF)

Requirements
•	WordPress 6.x or later
•	PHP 8.0 or later
•	Advanced Custom Fields (ACF) plugin
Installation
1.	Copy the gswajune folder into:
wp-content/themes/
2.	Activate the theme from:
Appearance → Themes
3.	Install and activate the Advanced Custom Fields (ACF) plugin.
4.	Import or create the required content.
